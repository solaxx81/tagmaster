# TagMaster

## Projet de formation Python  

Ce projet a pour but de mettre en ordre une bibliothèque de fichiers MP3 en complétant certains tags manquants :  

- nom de l'album
- année
- image de la pochette

La bibliothèque Python mutagen ainsi que l'API de MusicBrainz seront utilisées.
